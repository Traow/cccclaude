# Horizon – Animated

Custom animation layer and homepage sections for the store's Horizon theme.
These files are uploaded to the unpublished theme "Horizon – Animated (Claude)".

- `assets/cc-motion.css`, `assets/cc-motion.js` – scroll reveals, split-text headlines,
  parallax, 3D tilt, magnetic buttons, scroll progress bar, intro curtain.
  Everything is disabled for visitors with reduced motion enabled.
- `sections/cc-hero.liquid` – full-screen hero with a fanned, floating product stack.
- `sections/cc-marquee.liquid` – scrolling text band that skews with scroll speed.
- `sections/cc-showcase.liquid` – product spotlight with colour/size picker and add to cart.
- `sections/cc-colorways.liquid` – expanding colour panels.
- `sections/cc-features.liquid` – tilt cards.
- `templates/index.json`, `config/settings_data.json`, `sections/header-group.json`,
  `layout/theme.liquid` – homepage layout, dark palette and theme wiring.
